## Дополнительные проверенные срезы (для справки, не использованные выше запросы)

Гистограмма распределения срыва (слайд 2):

```sql
WITH overruns AS (
    SELECT project_code, MAX(fact_end) - MAX(plan_end) AS overrun_days
    FROM project_tasks
    GROUP BY project_code
    HAVING MAX(fact_end) IS NOT NULL
)
SELECT
    width_bucket(overrun_days, -10, 20, 6) AS bucket,
    MIN(overrun_days) AS lo, MAX(overrun_days) AS hi, COUNT(*) AS n
FROM overruns
GROUP BY bucket
ORDER BY bucket;
```

Динамика платежей по месяцам (опциональный слайд 7):

```sql
SELECT date_trunc('month', payment_date)::date AS month, SUM(amount_rub) AS total_rub, COUNT(*) AS n
FROM project_payments
GROUP BY month
ORDER BY month;
```
