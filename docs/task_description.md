# Описание задачи

> Текстовая копия `task_description.docx` — для чтения прямо на GitHub без скачивания. Оригинал docx лежит рядом.

Вы получили три несвязанных выгрузки из внутренних систем управления проектами (PMO), ИТ-департамента и финансового учёта. Вам необходимо провести комплексный аудит портфеля проектов, выявить критические отклонения в сроках и бюджетах, а также сформировать рекомендации для Проектного комитета.

## Требования к этапам работы

### Преобразование данных (ETL)

Очистить данные, привести форматы дат к единому стандарту `YYYY-MM-DD`, обработать пропуски и восстановить нарушенные связи между таблицами (исправить битые коды проектов).

### Анализ расписания (Time Management)

- Рассчитать плановую и фактическую длительность каждой задачи.
- Найти топ-5 проектов с максимальным суммарным срывом дедлайнов (разница между плановым концом проекта и фактическим).
- Выявить логические ошибки ведения планов.

### Финансово-ресурсный анализ

- Свести все бюджеты к единой валюте (RUB). Для расчёта использовать фиксированные условные курсы: 1 USD = 90 RUB, 1 EUR = 100 RUB.
- Рассчитать общую стоимость портфеля и среднюю стоимость одного проекта.
- Найти топ-3 PM по объёму освоенного бюджета.

### Бизнес-анализ ландшафта

- Разделить проекты на "Технологические" (где закупались Серверы и Системные блоки) и "Офисно-коммерческие" (где фигурируют только наушники, клавиатуры, бублики и кофе).
- Сравнить средний бюджет и среднюю задержку по срокам между этими двумя группами.

## Формат результата

Презентация в формате PDF/PPTX (до 6-7 слайдов), содержащая графики, ключевые метрики здоровья портфеля проектов и выводы для руководства. Приложение к выполненному заданию — чистый, документированный код (Python-скрипт или SQL-запросы).
